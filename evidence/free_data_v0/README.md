## 对下一步的实际影响

1. **日线长度已不是当前首要缺口。** 选定期间存在大量长度足够的分片，但当前 `lake_cut` 只固定三只证据探针。正式股票池必须逐日重建沪深主板归属、上市/退市、ST 与上市日龄，覆盖后来退市的证券，不能把 5,495 直接作为主板池。
2. **盘后信号仍缺当日可见性证据。** 该包是后来发布的历史归档，没有每个历史交易日 18:00 前可取得的版本或完成时间。L1 现有拒答是正确结果。若做探索，只能明确标 `reconstructed`，不能升级成 `verified_visible`。
3. **次日开盘仍缺正向状态。** 归档中的 `tradestatus`、`isST` 与参考昨收可用于事后排错和逐日状态对账；不能代替订单提交时刻以前已公开的可交易状态、价格限制、除权参考价和公司行为入账。因而不能将这些行直接送入开盘撮合后宣称市场回测已验收。
4. **先做有边界的两个取证样本。** 对退市证券，逐日核对公告版本、摘牌前日线、停牌与风险警示起止；对仍上市证券，在指定交易日盘后实时保存源实际返回时间、字段、版本和次日提交前状态。两类样本都通过后，再决定批量导入与研究区间。

本目录的数值是对已固定归档的复核，不推断源后来是否更新。重新下载、改脚本或补数必须生成新版本及差分，不覆盖这份证据。
